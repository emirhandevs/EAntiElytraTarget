# 🛡️ EAntiElytraTarget

Open-source anti-elytra-target plugin designed for **BoxPvP** Minecraft servers to prevent unfair mid-air combat advantages and keep PvP balanced.

---

## ✨ Features

* 🎯 **Smart Elytra-Target Prevention:** Detects and blocks unnatural mid-air combat advantages caused by Elytra momentum and targeting abuse.
* ⚡ **Lightweight & High Performance:** Designed to keep server TPS stable during heavy BoxPvP combat.
* 🔧 **Configurable (`config.yml`):** Customize detection thresholds, cooldowns, disabled worlds, and messages.
* 🔔 **Real-Time Staff Alerts:** Notify staff in-game when suspicious Elytra-targeting behavior occurs.
* 📦 **BoxPvP Focused:** Preserves normal Elytra movement and escape flow while targeting unfair combat abuse.

---

## 💻 Commands & Permissions

| Command | Description | Permission |
| :--- | :--- | :--- |
| `/eantielytratarget reload` | Reloads `config.yml` without restarting the server. | `eantielytratarget.admin` |
| `/eantielytratarget alerts` | Toggles in-game staff alert notifications on or off. | `eantielytratarget.alerts` |

---

## ⚙️ Installation & Building

1. Download the latest `.jar` release from **Modrinth** (or build from source).
2. Place the `.jar` file into your server's `/plugins` folder.
3. Restart the server to generate default configuration files.
4. Configure `plugins/EAntiElytraTarget/config.yml` and run `/eantielytratarget reload`.
